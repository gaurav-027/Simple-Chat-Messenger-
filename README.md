# 💬 Simple Chat App (Express + MongoDB + EJS)

A small **Full-Stack CRUD Chat Application** built using Node.js, Express.js, MongoDB (Mongoose), and EJS templating engine.  
This project demonstrates how to build a simple WhatsApp-style chat interface with full Create, Read, Update, and Delete functionality.

# 🚀 Project Overview

This app is a part of my backend learning journey.  
It focuses on understanding how server-side rendering works and how data flows between the frontend (EJS) and backend (Express + MongoDB).

# ✨ Features:
- ➕ Add new chat messages  
- 📜 View all chats  
- ✏️ Edit existing chat messages  
- ❌ Delete unwanted chats  
- 🕒 Automatically store message creation time  

# 🧠 What I Learned

- Setting up and configuring **Express.js** server  
- Connecting MongoDB with **Mongoose**  
- Using **EJS** templates to render dynamic data  
- Handling form data and **CRUD operations**  
- Implementing **method-override** to use PUT and DELETE in forms  
- Organizing a proper **MVC-style folder structure**
  
# 🏗️ Tech Stack

| Layer | Technology |
|-------|-------------|
| Backend | Node.js, Express.js |
| Database | MongoDB, Mongoose |
| Frontend | EJS, HTML, CSS |
